## Integration

Both pose images stay mounted within the persistent auth layout and are decoded before display. An available pose remains visible if the alternate image is still loading. Active art has high fetch priority; alternate art loads at low priority. A separate image skeleton is not needed inside the loaded auth layout. The slots use direct grid placement, with no cross-page movement. Following user feedback, auth navigation uses a 320ms route skeleton matching the destination columns; loaded content and decoded artwork appear without fade/slide effects. Reduced motion disables skeleton pulsing. Images remain `object-fit: contain`, with reserved 3:2 dimensions.
